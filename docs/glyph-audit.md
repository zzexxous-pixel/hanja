# 자형·획수·획순 대조 현황

2026-10-30. 공식 대조를 완료한 1,000자 데이터라고 주장하지 않는다.

## 조사 시작 결과
- 대상: 앱 실제 지원 1,000자(8급~3급), 중복 제거.
- 공식 근거가 확보된 획수: 敬 13획 1건(사용자 제공 자료/확인).
- 기본 hanzi-writer-data@2.0.1의 敬: 12획 → 현재 예외 데이터: 13획.
- 전체 자형/획순: 모두 검수 대기. 敬도 전체 순서·방향까지 공식 자료와 대조 완료된 상태는 아니다.
- 기본 데이터의 정확한 코드포인트가 없는 문자 16개 발견:
  敎 飮 窓 淸 擧 査 爲 眞 硏 絶 鄕 旣 郞 晩 顔 卽.
  비슷한 한자로 치환하지 않고 AnimCJK의 해당 문자 데이터로 보완했다.
  이 목록은 공식 자형 불일치 목록이 아니라 **기본 데이터 누락 목록**이다.
- 예외 17개는 manifest에 근거/원본/지역별 소스/버전/해시/검수 상태를 기록.
  한국어 소스에 없는 일부는 번체/일본 소스에서 정확한 코드포인트를 선택했다.
  해당 지역 자형이 대한검정회와 같다는 의미가 아니며 검수 전 상태를 공개한다.
- 부수 획 정보가 없는 보완 문자에는 임의의 부수를 만들지 않고 UI에 '부수 정보 미확인' 표시.

## 공식 자료 조사
- 대한검정회 등급별 선정한자: https://www.hanja.ne.kr/jupsu/jupsu07_01.asp
- 자료실: https://www.hanja.ne.kr/jupsu/jupsu07.asp
- 선정한자 페이지 텍스트로 8급30/7급50/6급70 안내는 확인했지만, 추출된 내용만으로는 1,000자 전체의 자형·총획·획순을 확보할 수 없다.
- 기출문제 페이지는 무단 전송/복제/배포/2차적 저작물 작성 금지를 명시한다. 기출 PDF/교재를 대량 복제하여 검수 사이트에 게시하지 않는다.

## 사용자에게 필요한 도움
대한검정회 8급~3급의 자형·총획 자료가 있는 공식 URL/파일 또는 확인용 교재/스캔을 제공받아야 대조를 완료할 수 있다.
획순까지 확인하려면 획순 도해/공식 시연도 필요하다. 자형 인쇄본만으로 획순을 추정하여 확정하지 않는다.
자료 공유 범위/이용 허가를 확인하고, 저작권 있는 원본은 공개 저장소·preview에 자동 재배포하지 않는다.
자료가 확보되면 에이전트가 전 글자 매핑, 자동 획수 대조, 시각 검토 후보 추출, 예외 작성/테스트를 진행한다.
모호한 교육 기준은 사용자 확인을 요청한다.

## 재현과 검수 화면
- `npm run audit:glyphs`: `_audit/index.html`, report.json, report.csv 생성. 생성물은 Git에서 제외.
- `npm run build:preview`: preview/review/에 검색 가능한 1,000자 검수표와 JSON/CSV를 함께 생성.
- 화면의 글꼴 표시는 **비교용 브라우저 글꼴이지 공식 견본이 아니다**.
- 적용 SVG는 실제 앱과 같은 데이터. 기존 기본 획수 → 적용 획수 / 공식 획수와 검수 상태를 표시.
- 공식 참조값은 `data/glyph-reference.json`에 출처와 함께 추가. 미확보 값은 null/미확인 유지.
- 미확인을 확인 완료로 바꾸려면 근거와 검수자를 기록할 것.
