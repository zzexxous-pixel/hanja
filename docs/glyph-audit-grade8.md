# 8급 30자 PDF 자형 1차 대조

검토일: 2026-10-30. 상태: 완성 자형의 1차 육안 대조, 사용자 확인 전. 앱 데이터 변경 없음.

## 기준 자료와 방법
- 사용자 제공: `8급 신출한자 훈음표.pdf` (1페이지).
- SHA256: `61cf899093aad828bf7d6e129988b87b577f378911bbc579472ae27b54ef9978`.
- PDF에 한자 글꼴이 포함되어 있어, 텍스트를 다른 폰트로 다시 출력하지 않고 PDF 내 글자 영역을 렌더링하여 비교했다.
- PDF의 문자별 bbox를 추출하고 앱 scripts/strokes.mjs의 실제 선택 데이터로 SVG를 생성하여 30개 모두 나란히 확인했다.
- 비교 이미지는 획 구조를 보기 위해 여백/크기를 정리했으므로 원본 인쇄 크기/자폭 비교용은 아니다.
- PDF의 파란 제목 배경이 月/二 영역과 겹쳐 렌더링된다. 비교용 사본에서 배경 도형만 제거하고 글자 자체는 유지했다. 원본 파일은 수정하지 않았다.
- 원본 PDF와 잘라낸 이미지는 Git/Pages에 넣지 않았다. `_audit/pdf8/` 내부 생성물은 Git 제외.

## 결과
자료의 30자와 앱 8급 30자가 모두 대응된다. 1차 시각 대조에서 구성요소 치환/누락 등 명백한 구조 차이는 발견하지 못했다.
이는 픽셀·윤곽의 완전 동일이나 대한검정회의 모든 필기 허용 기준을 인증한다는 뜻이 아니다.

검토한 글자:
九 金 南 男 女 東 六 母 木 門
父 北 四 三 西 水 十 五 月 二
人 日 一 子 弟 七 土 八 兄 火

- PDF는 인쇄체, 앱 SVG는 붓글씨/필기체 성격이어서 30자 모두 굵기·기울기·곡률·끝맺음·자폭 차이가 있다.
- 六: PDF 상단은 짧은 세로획 모양, 앱은 점 모양. 서체 차이로 보이나 인쇄 견본과 정확한 모양 일치가 목적이면 확인 대상.
- 父·八: 윗부분 짧은 획의 방향/길이, 획 시작점 간격 등 차이.
- 子: 윗부분 꺾임의 직선/곡선과 비례 차이.
- 이러한 차이를 교육상 오류라고 확정하거나 예외 데이터로 자동 교체하지 않았다.
- PDF 六의 텍스트 코드는 호환한자 六(U+F9D1), 앱은 六(U+516D). 목록 대응에는 정규화만 사용했으며 원본 모양은 PDF에서 그대로 확인했다.

## 이번 자료로 확인하지 않은 사항
- 총획수: 표에 총획수 없음. PDF의 인쇄 윤곽에서 획수를 추정해 공식값으로 입력하지 않는다.
- 획순/방향: 훈음표이므로 확인 불가.
- 나머지 급수: 미검토.
- data/glyph-reference.json의 shapeReviewed/orderReviewed 상태는 변경하지 않았다. 사용자 검토 기준 합의 후 검수 완료 처리할 것.

## 후속
사용자가 '같은 글자 구조면 허용'인지, '인쇄 견본의 세부 자형까지 일치'인지 비교 결과를 보고 확인하면 된다.
명백한 차이만 수정하는 기준이라면 이번 30자에는 신규 예외 추가를 권하지 않는다. 다른 급수도 같은 방식으로 진행 가능.
